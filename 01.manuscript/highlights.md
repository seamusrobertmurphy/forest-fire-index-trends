# Highlights

- The 1987 and 2025 Fire Weather Index versions were run on one record over 31 seasons
- Hourly FWI2025 raised days above Fine Fuel Moisture Code 91 from 57 to 62 a season
- None of 48 trend slope differences between the two versions excluded zero
- The three series predicted daily lightning ignitions almost equally well
- Report trends as days above a percentile threshold and state the index version
