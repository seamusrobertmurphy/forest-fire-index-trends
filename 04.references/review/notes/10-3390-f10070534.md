Subject. The paper concerned the Drought Code as a predictor of peatland water table and the use of that relation to switch peatland fuel types in a burn probability model, the basis of the peatland components added in 2025.

Establishes. Thompson and others fitted water table depth at 296 peatland sites visited between 1981 and 1989 in the boreal plain to the Drought Code in an analysis of covariance with canopy and nutrient class terms. The Drought Code alone explained 7 per cent of the variance and the full model 51 per cent, with the same decline of about 0.041 to 0.046 cm of water table per unit of Drought Code in every peatland type. Critical Drought Code values at which each peatland type became a flammable fuel ran from 250 for forested bog to 710 for open rich fen. In Burn-P3 simulations with identical weather, median burn rate rose 530 per cent at a Drought Code of 500 and 790 per cent at 750 against 250, and median fire size rose from 137 to 725 to 900 ha. The paper stated the System's inputs as daily noon measurements and the Drought Code's 2.8 mm rain threshold and 52 day drying constant. It did not compute any hourly code and did not test any index against observed fire occurrence.

Bears on

- Fire Danger Systems, "The optional grassland codes that FWI2025 added" (qmd L2467). The paper is the empirical basis for a peatland component, a water table falling about 0.041 to 0.046 cm per unit of Drought Code with thresholds of 250 to 710 by peatland type, fitted on 296 boreal plain sites. The relation needed canopy and nutrient class to reach 51 per cent of variance and was built for the boreal plain, so it supports excluding the peatland components from a comparison in the Okanagan.
- Fire Danger Systems, "FWI1987 was the version @vanwagner1987fwi specified." (qmd L2463), the clause on inputs of temperature, humidity, ten metre wind and rainfall. The paper stated the inputs as daily noon measurements of 2 m temperature, humidity, 10 m wind speed and rainfall, which supports the sentence and names the noon observation.
- Introduction, "Fire danger has been rated throughout Canada since 1970" (qmd L2188), the clause "Their rain thresholds of 1.5 mm and 2.8 mm". The paper stated that only daily precipitation above 2.8 mm replenished the Drought Code layer, which supports the 2.8 mm figure.
- Introduction, table of expectations, row "Mean Duff Moisture Code and peak Drought Code" (qmd L2209), the clause "the startup value moved the early season Drought Code". The paper gave the Drought Code drying constant, 66 per cent of the initial moisture lost after 52 days of constant drying, which adds the time scale over which a startup value persists.
- Seasonal Metrics, "Absolute thresholds applied unchanged to all three series." (qmd L2571). The paper used an Initial Spread Index above 8.5 as the regional day of probable fire spread, which adds a spread day threshold in Initial Spread Index units beside the Fire Weather Index of 19 the manuscript took from Podur and Wotton.
