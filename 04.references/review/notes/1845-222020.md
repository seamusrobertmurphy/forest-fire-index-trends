Subject. The diurnal adjustment of the Fine Fuel Moisture Code, a table that gave the code at other times of day from the noon code and the relative humidity.

Establishes. The report built the diurnal adjustment table of the revised Canadian fire danger rating system. Fine fuel moisture was sampled around the clock under dry lodgepole pine near Prince George, British Columbia, in 1966 to 1968. Moisture at each two-hour time was regressed on the noon code or measured 1600 hour moisture, and on relative humidity. Daily minimum moisture fell at 1600 hours, and the noon code was taken to apply to the 1300 to 1600 hour peak. The code was meant to equal 101 minus that minimum, but 144 samples showed otherwise, unevenly across the range. Moisture at every time was better related to measured 1600 hour moisture than to the code's estimate. Under pressure to start the revised system, the authors kept the theoretical relation. Lawson's 1967 tables, stepped from 0600 and 1600 hour codes, were not adopted because twice daily readings and rain corrections were impractical. The text adjusted a noon code by table and did not compute the code from hourly weather or compare a daily with an hourly series.

Bears on

- Introduction, "From one observation a day, taken at 13:00 local daylight time" (qmd L2186-2225). Adds history. In 1969 the standard daily calculation was at noon, 1200 hours, and that code was taken to apply to the peak burning period of 1300 to 1600 hours. The text did not say whether its clock was standard or daylight time.
- Introduction, "An hourly method for the Fine Fuel Moisture Code had existed since @vanwagner1977hourly" (qmd L2186-2225). Adds an earlier precedent. A table of bi-hourly adjustments to the code existed by 1969, after Beall's 1938 diurnal table, so the sentence holds only for a method computed from hourly weather.
- Introduction, "Its first listed key update was" (qmd L2186-2225). Adds early field evidence for the gap the update addressed. Under dry lodgepole pine near Prince George, daily minimum fine fuel moisture fell at 1600 hours, four hours after the noon calculation.
- Introduction, "The hourly noon values were biased low because" (qmd L2186-2225). Supports the reason given, with a 1969 measurement. The samples put the daily moisture minimum, and so the code's daily maximum, at 1600 hours rather than at noon.
- Study Design, "Under pathway C the 13:00 observation was converted to estimated daily maxima and minima" (qmd L2469-2476). Adds a precedent. The 1969 table also derived codes at other times from one daily code, but from the relative humidity measured at that time, not from an assumed diurnal curve.
- Seasonal Metrics, "The FWI2025 series were summarised to a daily value at 16:00 Local Standard Time" (qmd L2567-2576). Supports the hour chosen. The 1969 samples placed the daily minimum of fine fuel moisture at 1600 hours, though the text did not name the clock basis.
- Index Computation, "The coefficient that converted the Fine Fuel Moisture Code to a moisture content was printed as 147.2" (qmd L2561-2566). Adds history only. In the 1969 system the code was defined as 101 minus the daily minimum moisture content, and 144 samples showed the relation did not hold evenly.
- Discussion, "A daily index could not say when the peak arrived or how long it lasted" (qmd L3569). Adds history. The 1969 table existed so that the system could be applied at times other than noon, for prescribed burning and fire suppression.
