Subject. The calibration of the Duff Moisture Code against measured duff moisture content for forest floor types in coastal and southern interior British Columbia and southern Yukon, and its use to start a station late in the season.

Establishes. Lawson, Dalrymple and Hawkes of the Pacific Forestry Centre printed the national standard equation linking the Duff Moisture Code to duff moisture content, MC=exp[(DMC-244.7)/-43.4]+20. They added four regressions fitted to British Columbia and Yukon samples. The standard equation, calibrated on eastern red pine and jack pine duff, held for the Coastal Western Hemlock zone. That zone's duff depth and bulk density matched the 7 cm and 0.07 g/cm3 of the standard. Southern interior British Columbia duff from the IDF, MS, ICH and ESSF zones fell below the standard curve, with MC=exp[(DMC-223.9)/-41.7]+20. Southern Yukon duff exceeded the standard until the code passed about 35 to 50. A lookup table gave moisture content for codes 0 to 140. The equations were offered for ground-truthing a late-starting station. The text gave no observation time, no hourly method and no test against fire activity.

Bears on

- Introduction, "The Fine Fuel Moisture Code (FFMC) tracks the surface litter, the Duff Moisture Code the loosely packed duff beneath it and the Drought Code (DC) the deep compact organic layer." (qmd L2186-2225). Supports. Adds that the Duff Moisture Code's moisture meaning was calibrated on eastern pine duff and did not hold for southern interior British Columbia duff, which includes the Okanagan's zones.
- Fire Danger Systems, "The System rated the weather against one standard fuel, "a generalized pine forest (similar to C-3)"" (qmd L2459-2468). Supports, and adds the quantitative basis, 7 cm of duff at 0.07 g/cm3. A given Duff Moisture Code meant a lower moisture content in the southern interior than in the standard fuel, so a code trend in the Okanagan was a trend in a provincially calibrated quantity.
- Lines citing the 2025 report elsewhere, "It replaced the Canadian start rule, which began the calculation three days after the snow cover disappeared" (qmd L2551). Adds. The text gave the operational method for starting a station mid-season, sampling duff and inverting the equation, and said the Duff Moisture Code needed no overwinter adjustment, unlike the Drought Code.
- Introduction, table of expectations, row "Mean Duff Moisture Code and peak Drought Code". Adds. A comparison of mean Duff Moisture Code levels between versions concerned a code whose calibration to duff moisture was itself regional.
