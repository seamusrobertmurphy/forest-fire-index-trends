Subject. The national diurnal adjustment table that turned the standard daily Fine Fuel Moisture Code, observed at 1300 daylight saving time, into codes for other hours of the day.

Establishes. M.E. Alexander reissued the diurnal adjustment table for the Fine Fuel Moisture Code in Edmonton in November 1982. It revised the 1973 British Columbia supplement BC-6 and the 1974 Ontario supplement ONT-3, with a table after Van Wagner (1972). Daily observations were taken at 1300 daylight saving time, 1200 local standard time. The daily code was projected to the assumed peak of fire danger at about 1600 to 1700, near the minimum of fine fuel moisture. In the table, whose times were daylight saving time, the 1700 row equalled the standard daily code. The 1300 row was lower, 89 where the daily code was 91. Morning rows took three humidity classes, and appreciable rain after 1300 invalidated the procedure. The slow codes and Buildup Index were held at their last observed values. Users with continuous hourly weather and a programmable calculator were pointed to Van Wagner's 1977 hourly method. The note reported no data or test of the table.

Bears on

- Introduction, "From one observation a day, taken at 13:00 local daylight time" (qmd L2186-2225). Supports it directly. The 1982 note put daily observations at 1300 daylight saving time, 1200 local standard time, with daylight time from the last Sunday in April to the last Sunday in October.
- Seasonal Metrics, "The FWI2025 series were summarised to a daily value at 16:00 Local Standard Time" (qmd L2567-2576). Supports the hour chosen. The table's 1700 row, in daylight saving time, equalled the standard daily code, and 1700 daylight time is 1600 standard time.
- Seasonal Metrics, "FWI1987 'lacks a precise definition for the time to which its outputs are correlated'" (qmd L2567-2576). Qualifies the report's claim. The 1982 national table equated the daily code with the code at 1700 daylight time, though its prose called the peak approximate, at 1600 to 1700.
- Introduction, "The report's section 4.1 nonetheless claimed continuity" (qmd L2186-2225). Adds a caution on matching hours. In the 1982 table a daily code of 91 read 89 at the 1300 observation hour and 90 at 1500, reaching 91 only at 1700.
- Seasonal Metrics, "A Fine Fuel Moisture Code of 91 was taken from section 4.1" (qmd L2567-2576). Adds the same caution. A daily FWI1987 code of 91 stood for the late afternoon, so an hourly FWI2025 code compares with it only at a matched hour.
- Introduction, "An hourly method for the Fine Fuel Moisture Code had existed since @vanwagner1977hourly" (qmd L2186-2225). Supports it. The note named Van Wagner (1977) as the method for any hour, given continuous hourly weather and a computer or programmable calculator.
- Study Design, "Under pathway C the 13:00 observation was converted to estimated daily maxima and minima" (qmd L2469-2476). Adds a precedent. The 1982 table also expanded the 1300 code to other hours, assuming one afternoon humidity trend, and was invalid after appreciable rain.
- Discussion, "A daily index could not say when the peak arrived or how long it lasted" (qmd L3569). Adds history. The 1982 guidance assumed the same peak, at about 1600 to 1700, on every day.
- Fire Danger Systems, "Its inputs were air temperature, relative humidity, wind speed at ten metres in the open" (qmd L2459-2468). Supports the wind standard. The note specified the 10-minute average wind speed in km/h at the standard height of 10 m in the open.
- Introduction, "It is the part of the Canadian Forest Fire Danger Rating System that models fuel moisture" (qmd L2186-2225). Adds naming history. By 1982 the Canadian Forest Fire Behavior System of the 1973 and 1974 supplements had been renamed the Canadian Forest Fire Danger Rating System.
