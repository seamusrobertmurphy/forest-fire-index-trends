Subject. The British Columbia table for the Fine Fuel Moisture Code and Fire Weather Index at times of day other than the noon observation.

Establishes. Issued by the Pacific Forest Research Centre in Victoria in August 1973, the supplement tabled the Fine Fuel Moisture Code for other times of day. It was a supplement to what it called the Canadian Forest Fire Behaviour System. Routine observations were taken at noon local standard time. The daily index they gave stood for the peak mid-afternoon danger period, normally around 3 to 4 p.m. The table read the latest noon code and the time of day. For morning times it also read the relative humidity then, to allow for incomplete overnight recovery. An index for the same time came from the adjusted code, the wind then and the latest noon Buildup Index, through the standard tables. The table's times were local standard time, with one hour added under daylight saving. It held only in the absence of rain. The supplement cited Muraro and others (1969) and Van Wagner (1972) and gave no data or evaluation of its own.

Bears on

- Introduction, "From one observation a day, taken at 13:00 local daylight time" (qmd L2186-2225). Supports it and gives its basis. The 1973 supplement put routine observations at noon local standard time and added one hour under daylight saving, which is 13:00 daylight time.
- Seasonal Metrics, "The FWI2025 series were summarised to a daily value at 16:00 Local Standard Time" (qmd L2567-2576). Adds a British Columbia definition. In 1973 the daily index stood for the peak mid-afternoon period, normally around 3 to 4 p.m., so 16:00 sat at its late edge.
- Seasonal Metrics, "FWI1987 'lacks a precise definition for the time to which its outputs are correlated'" (qmd L2567-2576). Adds an earlier regional statement. The 1973 text named 3 to 4 p.m. without stating its clock, and in local standard time that window would be 16:00 to 17:00 daylight time.
- Introduction, "An hourly method for the Fine Fuel Moisture Code had existed since @vanwagner1977hourly" (qmd L2186-2225). Adds an earlier precedent. An hourly adjusted code table was issued for British Columbia in 1973, citing Van Wagner's 1972 table, so the sentence holds only for a code computed from hourly weather.
- Study Design, "Under pathway C the 13:00 observation was converted to estimated daily maxima and minima" (qmd L2469-2476). Adds a precedent. The 1973 table also expanded the noon code to other hours, but from humidity and wind measured or estimated at the hour, and only without rain.
- Discussion, "A daily index could not say when the peak arrived or how long it lasted" (qmd L3569). Adds history. The 1973 supplement gave the code and index at other times for slash burning and wildfire control, holding the Buildup Index at its noon value.
- Fire Danger Systems, "FWI1987 was the version @vanwagner1987fwi specified." (qmd L2459-2468). Adds the older names. In 1973 British Columbia called the parent system the Canadian Forest Fire Behaviour System and the Buildup Index the Adjusted Duff Moisture Code.
